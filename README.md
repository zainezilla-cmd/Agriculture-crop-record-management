# Agriculture Crop Record Management System

A Python object-oriented programming project for managing basic crop records.

## Course
PROG211 – Object-Oriented Programming 1

## Project Description
The Agriculture Crop Record Management System is a Python console application that helps users register and manage crop records.

## Features
- Add a crop record.
- Display all crop records.
- Search for a crop using its ID.
- Update the harvest quantity.
- Count crop records.
- Validate user input.

## Object-Oriented Programming Concepts
The project demonstrates:
- Classes and objects.
- Attributes and methods.
- Instance methods.
- Class methods.
- Static methods.

## Data Structure
A Python list stores crop objects while the program is running.

## Requirements
- Python 3.
- Python IDLE or another Python editor.

## How to Run
1. Download the `crop_management.py` file.
2. Open it using Python IDLE.
3. Press F5 to run the program.
4. Follow the instructions displayed in the menu.

## Testing
The program should be tested by adding, displaying, searching for and updating crop records. Input validation should also be checked. Record the actual results of the tests performed.

## Limitations
Crop records are stored in memory and are not saved permanently when the program closes.
